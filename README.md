A program that draws one invented passport spread — the data page and visa page of the Republic of Caldara, a volcanic island republic that does not exist — and writes it to /output/entry.png. Holder Elena Ivana Marova, issued 12 March 2023 in Port Ember; entry and exit stamps from Tarnovia, Maren and Sarn tell a travel history that agrees with the passport's dates, and the conditions box (geothermal permit required in the caldera districts) says what kind of place Caldara is.

## Run it

```sh
python3 main.py
```

Requires Python 3.13 and Pillow. Deterministic: the same run always writes the same PNG.
